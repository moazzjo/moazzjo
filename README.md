### ⚙️ Engineering Practice

I follow a formal software engineering approach before implementation:

- **Software Requirements Specification (SRS)**
- **System Design Document (SDD)**
- **UML Diagrams**:
  - Use Case Diagrams (system scope)
  - Activity Diagrams (business workflows)
  - Sequence Diagrams (system interaction)
  - ER Diagrams (data modeling)
- **Software Design Patterns** for maintainable, scalable architecture
- **Requirements Gathering & Analysis** before any line of code
